# 社团小程序

基于微信云开发（云函数 + 云数据库 + 云存储）的社团管理小程序，覆盖活动报名、活动照片管理、新闻公告、社费管理、意见反馈与吉祥物展示等功能。

## 功能特性

- **欢迎页**：Canvas 逐帧播放 101 帧开屏吉祥物动画（欢迎页 → 菜单页 → 首页）
- **活动**：活动列表（进行中 / 未开始 / 已结束按时间状态排序）、活动详情、报名 / 取消报名、活动照片分组展示
- **活动照片**：按分组（选手图片 / 大合照等）管理活动照片，支持文字说明、原图预览，管理员可在后台增删改
- **新闻 / 公告**：分类浏览、置顶、详情
- **社费**：余额查询 + 流水记账（管理员）
- **用户**：微信登录，昵称 / 个人简介，我的报名
- **管理端**：活动管理、新闻管理、社费管理、吉祥物管理、活动照片管理、报名名单导出 CSV
- **意见反馈**：内容 + 联系方式提交
- **吉祥物**：神人 / 咕嘎两类角色展示

## 运行方式

1. 使用微信开发者工具导入本目录。
2. 在 `project.config.json` 中确认 AppID 与云环境 ID。
3. 上传并部署 `cloudfunctions/` 下的云函数（并安装各函数依赖）。
4. 在云开发控制台创建集合：`users`、`activities`、`news`、`signups`、`fund_records`、`feedback`、`mascots`、`photos`。
5. 编译运行小程序。
