# 神人社团小程序

基于微信云开发（云函数 + 云数据库 + 云存储）的社团管理小程序，覆盖活动报名、新闻公告、社费管理、草案提案审核、表情包与吉祥物展示等功能。

## 技术栈

- 前端：微信小程序原生开发
- 后端：微信云开发（云函数 + 云数据库 + 云存储）
- 云环境 ID：`cloudbase-d4gsr6mb93c4808e3`

## 目录结构

```
miniprogram/        小程序前端
cloudfunctions/     云函数（40 个）
项目说明.md          项目全景说明（结构、页面、云函数、业务流程）
代码说明.md          代码规范实践指南
```

## 运行方式

1. 使用微信开发者工具导入本目录。
2. 在 `project.config.json` 中确认 AppID 与云环境 ID。
3. 上传并部署 `cloudfunctions/` 下的云函数。
4. 编译运行小程序。
