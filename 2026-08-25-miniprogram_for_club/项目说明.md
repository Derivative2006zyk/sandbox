# 社团小程序 - 项目全景说明

> 本文件面向接手项目的 AI / 开发者，目标是"看完就能定位任何文件、理解任何模块"。全量梳理了项目结构、每个文件的作用、数据库集合、云函数、页面与业务流程。

## 1. 项目概述

- **项目名称**：神人社团小程序（`miniprogram_for_club`）
- **类型**：微信小程序（原生开发，非 uni-app / taro），后端全部使用**微信云开发（云函数 + 云数据库 + 云存储）**
- **AppID**：`wx2a723ec1d92af1b7`
- **云环境 ID**：`cloudbase-d4gsr6mb93c4808e3`（在 `app.js` 中硬编码初始化）
- **基础库版本**：`2.20.1`（`project.config.json`），代码中要求 >= 2.2.3 以启用云能力
- **功能定位**：社团内部的"活动报名 + 新闻公告 + 社费管理 + 草案提案审核 + 表情包 + 吉祥物展示"一站式小程序，含普通用户端与管理员端。

### 吉祥物 / 品牌
- 社团吉祥物分两类：**神人（shenren）**、**咕嘎（guga）**，图片存于云存储 `mascots/` 目录。
- 欢迎页开屏动画是一段 **101 帧**的逐帧 PNG 动画（`shiroko_png8/frame_000001.png` ~ `frame_000101.png`）。

**关键约定**：
- 前端页面文件 = `index.js`（逻辑）+ `index.wxml`（结构）+ `index.wxss`（样式）+ `index.json`（页面配置）。
- 每个云函数目录 = `index.js`（`exports.main`）+ `package.json` + `config.json`。
- 前后端通过 `wx.cloud.callFunction({ name, data })` 通信，返回统一协议：`{ code, msg, data }`，`code === 0` 表示成功。

## 7. 核心业务流程

### 7.1 登录与资料完善
1. 任意页面调 `app.login()` -> `login` 云函数按 OPENID 查/建用户。
2. 若 `isNew === true`（首次登录），首页 `checkLogin` 跳转"完善资料"页。
3. 完善资料调 `updateUser`，写回 `globalData.userInfo`。

### 7.2 活动报名
1. 用户点活动详情 -> `getActivityDetail` 返回活动 + `isSignedUp`。
2. 点报名 -> 校验资料完整 -> 跳"活动报名"页填表 -> `signup` 云函数。
3. `signup` 做全量校验后，用**数据库事务**同时写报名记录 + 人数 +1，保证一致性。
4. 取消报名同理，事务写 status=2 + 人数 -1。

### 7.3 草案提案 -> 审核
1. 用户提交草案（活动/新闻/表情）-> `submitDraft`，状态 `pending`。
2. 管理员在"草案审核"页 `getPendingDrafts` 查看，批准/拒绝 -> `reviewDraft`。
3. 批准活动/新闻草案 -> **生成一条公告**（`isDraftProposal: true`）放入 `news`；批准表情草案 -> jimp 压缩后入 `emoji`。

### 7.4 社费记账
- `getFundInfo` 用"最新一条记录的 afterBalance"作为当前余额（**流水式记账，非独立余额字段**）。
- 管理员记账 `updateFund`：计算 `beforeBalance/afterBalance`，拒绝负余额。

### 7.5 欢迎页动画
1. `getWelcomeAssets` 返回 101 帧 PNG 临时链接。
2. 前端下载到 `USER_DATA_PATH/welcome_frames`，用 `wx.setStorageSync('welcome_frames_cache')` 缓存（24h）。
3. Canvas 逐帧绘制（12fps），实现开屏小人动画。

## 8. 权限模型

- **角色字段**：`users.role`，`0` = 普通用户，`1` = 管理员。
- **管理员判定**：云函数内 `users.where({ _openid: OPENID }).get()` 后检查 `role === 1`，否则返回 `{ code: 403, msg: '无权限操作' }`。
- **当前项目没有**独立的管理员设置入口/界面（`role` 字段需在云开发控制台手动改，或后续开发补）。
- 前端"我的"页**无 role 判断**地显示管理入口（`goAdmin` 直接可点），真正的权限拦截在云函数层。

## 10. 待注意 / 遗留问题（供后续开发参考）

1. **管理员设置缺失**：无 UI 或脚本把用户 `role` 设为 1，目前只能手动在云开发控制台改库。
2. **`createNews` 的 `sharp` 依赖未使用**：`package.json` 声明但代码未调用，可清理。
3. **`getActivityList` 无分页上限参数上限**：活动按 startTime 升序，首页与菜单页共用，`pageSize` 由前端传。
4. **背景图获取**：大部分页面 `fetchBgUrl()` 无超时保护（仅 news/detail 和 user/signups 有 `Promise.race` 超时），云函数异常时会走本地 `/images/background.jpg` 兜底。
5. **评论时间格式**：`formatCommentTime` 在 activity/detail 页内实现（刚刚/N 分钟前/N 小时前/N 天前），其他页面未复用。
6. **`getWelcomeAssets` 帧数硬编码**：默认 `totalFrames=101`，fileID 前缀写死为 `shiroko_png8/frame_` + 6 位序号。
